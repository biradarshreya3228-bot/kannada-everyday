Kannada Everyday Companion 🇮🇳

About the Project

Kannada Everyday Companion is a beginner-friendly web application designed to help people learn and use common Kannada words and phrases in everyday situations.

Problem Statement

People who are unfamiliar with Kannada may find it difficult to communicate while travelling, shopping, or visiting hospitals. This project provides a simple way to learn useful Kannada expressions.

Features

- Search: Find useful Kannada words and phrases.
- Categories: Explore Travel, Shopping, and Hospital phrases.
- Favorites: Save frequently used phrases.
- Quick Practice Quiz: Test your Kannada knowledge.
- Flashcards: Learn Kannada words with pronunciation and English meanings.
- Learned Words: Mark words as learned and track your progress.

Technologies Used

- HTML
- CSS
- JavaScript
- Browser Local Storage

How to Run

1. Download or clone this repository.
2. Open "index.html" in a web browser.
3. Start exploring the categories, flashcards, and quiz.

Project Goal

To make learning practical Kannada words easier, more accessible, and useful for everyday communication.
